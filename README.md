## Selected work

**[DeepRezearch](https://github.com/Smoodust/DeepRezearch)** — a multi-agent system for deep
research. An orchestrator routes a question to specialist research, coding and synthesis
agents, then assembles the final answer. Python, FastAPI and Ollama, deployed with Docker
Compose, with NVIDIA GPU support for local inference.

**[manga-reader](https://github.com/Smoodust/manga-reader)** — a full-stack app that extracts
Japanese dialogue from manga pages using OCR, built for people studying the language.
React frontend, FastAPI backend, containerized end to end.

**[sgu-hack](https://github.com/Smoodust/sgu-hack)** — ERRORHACK hackathon project for BaseALT:
clustering and semantic analysis of errors in Linux package builds. FastText and ONNX on the
ML side, PostgreSQL, a React/TypeScript frontend, and monitoring through Grafana, Prometheus
and Loki. Built in a team of four.

**[smart-house](https://github.com/Smoodust/smart-house)** — a self-hosted smart home platform.
Devices register over MQTT, a bridge service validates their messages and routes them through
Kafka, and telemetry lands in Postgres. Spring Boot and Java 21, with JWT auth, Mosquitto
ACL callbacks, Liquibase migrations and Prometheus/Grafana monitoring.

### Избранные проекты

**[DeepRezearch](https://github.com/Smoodust/DeepRezearch)** — мультиагентная система для
глубоких исследований. Оркестратор направляет запрос профильным агентам — исследовательскому,
кодовому и синтезирующему — и собирает итоговый ответ. Python, FastAPI, Ollama, разворачивается
через Docker Compose, поддерживает инференс на NVIDIA GPU.

**[manga-reader](https://github.com/Smoodust/manga-reader)** — full-stack приложение, которое
распознаёт японский текст на страницах манги через OCR. Сделано для тех, кто учит язык.
Frontend на React, backend на FastAPI, всё в Docker.

**[sgu-hack](https://github.com/Smoodust/sgu-hack)** — проект для хакатона ERRORHACK от СГУ по
заказу BaseALT: кластеризация и семантический анализ ошибок сборки Linux-пакетов. FastText и
ONNX для ML, PostgreSQL, фронтенд на React и TypeScript, мониторинг на Grafana, Prometheus и
Loki. Команда из четырёх человек.

**[smart-house](https://github.com/Smoodust/smart-house)** — платформа умного дома на
собственном хостинге. Устройства регистрируются и общаются по MQTT, сервис-мост проверяет
сообщения и маршрутизирует их через Kafka, телеметрия складывается в Postgres. Spring Boot и
Java 21, JWT-авторизация, ACL-колбэки для Mosquitto, миграции через Liquibase, мониторинг на
Prometheus и Grafana.
